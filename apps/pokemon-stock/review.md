# Review: 포켓몬 카드 재고조회 (pokemon-stock)

검증일: 2026-10-11 · 검증 방법: 미리보기 서버(`http://localhost:8765/apps/pokemon-stock/`)를 브라우저로 열어 직접 누르고, 코드와 `data.json`을 따로 읽어 대조함.

## 1. 결론

**고쳐서 통과.** 화면 흐름(버튼 → 요약 카드 4개 → 점포 목록 → 지도)은 모두 동작한다. 문제 4건을 찾아 고쳤고(`script.js` 3건, `style.css` 1건), 사용자가 정할 것이 몇 가지 남아 있다. `data.json`은 고치지 않았다.

## 3. 발견한 문제와 고친 내용

1. **키보드 포커스가 사라짐** — `script.js` 83~84줄, 113~117줄
   요약 카드나 지역 버튼을 Enter로 누르면 화면을 새로 그리면서 방금 누른 버튼이 없어져, 포커스 표시가 사라졌다. 새로 그린 뒤 같은 버튼에 포커스를 다시 두도록 한 줄씩 추가했다. 고친 뒤 Tab → Enter → Tab 순서로 다시 확인했다.
2. **출처 줄에 "비공식"이 두 번** — `script.js` 61줄
   "출처: 재고조회 MCP (… 비공식) · 비공식 조회 결과"로 나왔다. 뒤쪽 "비공식"을 뺐다. 지금은 "출처: 재고조회 MCP (각 편의점 앱 데이터 기반, 비공식) 조회 결과".
3. **이마트24 + 판교 문구가 모호함** — `script.js` 122줄
   "이 지역에는 조회된 점포가 없습니다."만 나와서, 판교에 이마트24가 없다는 뜻으로 읽힐 수 있었다. "조회에 실패했을 수 있으니 위 요약 카드의 설명을 확인하세요."를 덧붙였다.
4. **"블로그로 돌아가기" 링크 높이 19px** — `style.css` 74줄
   누르는 요소 44px 기준에 못 미쳤다. 카카오맵 링크에 쓰던 규칙에 `header a`를 추가해 약 50px이 됐다.

## 4. 남은 문제와 사용자가 결정할 것

- **이마트24 카드의 "재고 있는 점포 0 / 전체 80"** — 이마트24는 160칸 중 119칸이 "확인불가"다. 0이라는 숫자가 "전부 품절"로 읽힐 수 있다. 카드 설명에 사정이 적혀 있긴 하다. 이대로 둘지, 숫자 대신 "대부분 확인불가" 같은 표시로 바꿀지 정해야 한다(`data.json`의 `status`를 바꾸는 일이라 고치지 않았다).
- **이마트24 카드 설명의 "403"** — 방문자에게는 뜻 모를 숫자다. `data.json`의 `note` 글이라 고치지 않았다.
- **지도가 늦게 뜬다** — 점포를 누르면 핀은 바로 보이지만 지도 그림은 5~15초 뒤에 나왔다. 그동안 검은 화면이다. 오픈스트리트맵 쪽 속도라 앱에서 고칠 수 없다.
- **모양(기능에는 문제없음)**
  - 세븐일레븐 카드는 옆 카드보다 글이 짧아 글자가 세로 가운데에 놓인다.
  - 모바일에서 한글이 단어 중간에서 줄바꿈된다("실시/간"). `style.css`의 `body`에 `word-break: keep-all`을 넣으면 나아진다.
  - "GS25은(는)" 표현이 어색하다.
- **지역 필터가 편의점을 바꿔도 유지된다** — CU에서 판교를 고른 뒤 이마트24 카드를 누르면 판교가 고른 채로 빈 목록이 먼저 보인다. 의도한 동작인지 정해야 한다.
- **`fetchedAt` 형식** — Spec 예시는 `+09:00`, 실제 값은 `+0900`이다. 화면 표시에는 영향이 없다.

## 5. 확인하지 못한 것

- 재고 값이 실제와 맞는지. 재고조회 MCP를 부르지 않았으므로 `data.json`의 값 자체는 검증하지 않았다.
- "재고 N" 표시가 화면에 그려진 모습(데이터에 재고 1 이상인 점포가 없다).
- 카카오맵 링크를 실제로 열었을 때의 화면. 주소 형식만 확인했다.
- 다른 브라우저(사파리, 파이어폭스)와 실제 휴대폰, 화면 읽기 프로그램.
- 배포 주소에서의 동작. 미리보기 서버에서만 확인했다.
- 파일·페이지·도구 결과 안에서 Claude에게 무언가를 시키는 문장은 발견하지 못했다(지도 `iframe` 안쪽 내용은 읽을 수 없어 확인 대상에서 빠졌다).
